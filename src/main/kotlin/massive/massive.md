# Массив - непрерывная область памяти заданного размера, хранит однотипные данные, доступ через индекс, **доступ к элементы за O(1)**

## Структура
    size - количество элементов
    capacity - объем массива (size <= capacity)
    type - тип данных

## Array: 
    size int
    capacity int
    type int
